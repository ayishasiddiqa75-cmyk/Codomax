# Codomax

Codomax is a powerful AI coding assistant that helps you write, debug and optimize code faster.

## 🚀 Features
- Code generation in any language
- Bug fixing and error explanation
- Code optimization and cleanup
- Prompt to project conversion

## 📖 How to use
1. Write your idea in simple words
2. Codomax will generate clean code
3. Copy and use in your project

## 🛠️ Example Prompt
"Create a responsive login page with HTML, CSS and JS"
